MediaForge includes FFmpeg (https://ffmpeg.org), used unmodified as separate programs (ffmpeg, ffprobe).

This build is FFmpeg 9.0.2, a static macOS build by Helmut K. C. Tessarek (https://evermeet.cx/ffmpeg/).

Source code: FFmpeg's source is at https://ffmpeg.org/download.html; the exact build configuration and
the source of the bundled libraries are listed at https://evermeet.cx/ffmpeg/.
